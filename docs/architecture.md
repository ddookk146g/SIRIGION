# Архитектура модульной системы

## Базовые принципы

- Каждый модуль независим.
- Связь между модулями через `game.championshipCore.api`.
- Все данные хранятся через Foundry flags/settings.
- Основной UI — Journal Sheets и Application.
- Все сущности должны быть расширяемыми.

## Основные модули

- championship-core
- championship-company-sheet
- championship-enterprise-sheet
- championship-market
- championship-construction
- championship-storage
- championship-logistics
- championship-contracts
- championship-taxes
- championship-loans
- championship-national-projects
- championship-admin-panel
